# Orbit Notes v0.15 beta

- Preserves all circles and connections within the selected map when changing focus.
- Animates the camera to the selected note over 560 ms instead of replacing the hierarchy.
- Parent nodes remain in the same map and can be tapped to return.
- Keeps the v0.14 library, menus, icon and map gestures.

Known limitation: large or deeply nested maps may exceed the current drawing bounds or have overlapping branches. Physical-device testing is required.
